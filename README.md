# gazewarp-offline-dist

Release artefacts for **GazeWarp Offline**.

The installer at <https://gazewarp.com> downloads `gazewarp.zip` from the
`latest` release of this repository. Nothing else lives here.

## Install

```powershell
irm https://gazewarp.com/offline/install | iex
```

## Source

Source code is in a separate private repository; contact
<https://gazewarp.com> for access.

## Releases

Each release has one asset: `gazewarp.zip`. The `latest` tag always points
at the current production build.
